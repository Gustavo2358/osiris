# Marca Osiris

O logo usa o desenho enviado pelo usuário: olho na parte superior, trono à
esquerda e figura sentada voltada para a esquerda. O olho e o trono são dourados;
a figura é verde jade sobre fundo azul escuro. O mesmo arquivo atende cabeçalho,
estado inicial, carregamento e favicon.

- [Logo aplicado](../../public/osiris.png)
- [Referência original preservada](osiris-reference.png)
- Método: edição com a ferramenta integrada `image_gen`, usando a imagem anexada.
  Não depende de fontes, bibliotecas de ícones ou arquivos fora do repositório.
